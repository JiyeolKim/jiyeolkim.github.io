# 김지열 개발 포트폴리오

AI · Computer Vision · Mobile · Embedded 개발 경험을 소개하는 정적 웹사이트입니다.

HTML, CSS, JavaScript로 구성되어 있으며 별도의 빌드 과정이 필요하지 않습니다.

## 수정

- `index.html`: 소개와 프로젝트 목록
- `app.js`: 프로젝트 상세 내용과 화면 동작
- `styles.css`: 화면 디자인과 반응형 레이아웃

## GitHub Pages

저장소의 **Settings → Pages**에서 **Deploy from a branch**, **main**, **/(root)**를 선택하면 배포할 수 있습니다.
